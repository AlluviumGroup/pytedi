# pytedi

This is a new python version of the Tool for Estimating Dam Impacts (TEDI).

## Description

TEDI was originally conceived in the late 1990s by the Victorian government, the Murray Darling Basin Commission, and Sinclair Knight Merz.
It has been through many incarnations and used for many purposes. The latest windows version is available from Jacobs website: https://www.jacobs.com/natural-resource-management
This version is intended as a replacement for the Windows version to improve workflow efficiency and reduce scope for manual errors.

This version is still under development.
